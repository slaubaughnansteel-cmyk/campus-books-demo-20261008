# 拾页 · 让好书，再遇见

重新设计的校园二手书交互网站。纸张米白、松绿与陶土色搭配原创 CSS 书封，适配手机和桌面浏览器，无水印，无外部脚本、字体或图片依赖。

## 功能

- 书名、作者、ISBN 搜索；学院和类型筛选；价格及发布时间排序。
- 图书详情、收藏、浏览历史、购物车和数量计算。
- 封面图片压缩上传、发布、下架；ISBN 校验、本地书架匹配和发布信息带入。
- 支持 BarcodeDetector 的浏览器可识别照片中的 EAN-13 条码，不支持时使用手动输入。
- 本机演示预约、面交地点、体验书券、确认收书、评价、取消和售后登记。
- 明确标识的咨询演示；个人资料、咨询记录、收藏、订单等在 localStorage 保存。

## 使用范围

这是前端交互体验版。示例书架数据不是真实商品库存；发布和记录只保存在当前浏览器，不跨设备同步。支付、实名认证、真实消息和真实退款服务尚未接入。用户输入在渲染时进行 HTML 转义，应用不会发送这些数据到服务器。清除浏览器数据会清空本机记录。

## 本地预览

保持 `index.html`、三个 CSS 文件、`app.js` 和 `favicon.svg` 在同一目录，然后使用浏览器打开 `index.html`。也可通过任意静态文件服务器预览。
